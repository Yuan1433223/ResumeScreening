## 1. micro P/R/F1（事实级）

**计数单位：一条事实 = `kind + 归一化 value` 的二元组。**

- 归一化：年限类（`total_years`/`relevant_years`）`int(round(float(v)))`；其余 `str(v)`（`normalize_fact_value`）。
- TP（matched）：抽取产出中 `status==supported` 的事实集合 ∩ GT 事实集合。
- FP（spurious）：抽取的 supported 事实 − GT。
- FN（missing）：GT − 抽取的 supported 事实。
- **只统计含 GT 的文档**（`gt_facts` 非空）；空壳骨架文档不参与，避免稀释 micro。所有已标注文档 pooled 后一次性算，不做文档级再平均。

```
P = matched / extracted_facts
R = matched / gt_facts
F1 = 2PR / (P + R)
```

口径争议（单列不藏）：值精确匹配较严——模型产出"相近但不同档位"（如 `led` vs `responsible`）计未命中，属预期；逐份看 `detail.jsonl` 的 `spurious`/`missing` 列分析。

## 2. 转人工率

```
转人工率 = 触发转人工标记的文档数 / 总文档数
```

触发判定（`review_triggered`）：`report.warnings` 任一含以下标记——`转人工 / 人工复核 / 定位失败 / 抽取失败 / 未启用 / 未配置 / 无法解析 / 正文为空`。

**这是体验与成本的关键约束**：任何加固/优化不得显著推高它；每次改动复跑对比前后值。

## 3. 引用定位有效率与截断引用率

- **证据定位有效率** = 被成功定位的事实数 / 总事实数。定位成功 = `0<=start<end<=len(page.text)` 且 `page.text[start:end] == evidence.quote`（程序按子串计算偏移，模型不直接算偏移）。
- **截断引用率** = 截断引文数 / 成功定位引文数（启发式）：引文起点前一字符或终点后一字符是 ASCII 字母/数字/下划线（切在词中间，如 `'achieveme'`、`'期望薪资：4'`）。CJK 无词边界，中文字符截断不算——这是提示词质量信号，不是硬性 bug。
- 辅助：平均引文长度（按事实数加权）。

## 4. 成本与单份成本

```
总成本(分) = input_tokens/1000 × cost_per_1k_input_cents
           + output_tokens/1000 × cost_per_1k_output_cents
单份成本   = 总成本 / 文档数
```

价目从 `.env` 的 `MODEL_COST_PER_1K_INPUT_CENTS` / `MODEL_COST_PER_1K_OUTPUT_CENTS` 读；**未配置时总成本记 0 并注明"价目未配置"**——只能报 token 量级，不得谎称"成本极低"。

## 5. 延迟 P50/P95

```python
idx = int((len(sorted_durations) - 1) * p)   # p=0.5 / 0.95，最近秩法
```

只累计 `stats.duration_s > 0` 的文档；串行模型调用约 50–80s/份，批量并发未实现前 P95 天然偏高，报告里如实写。

## 6. 跨运行一致性（同输入两次 diff 率）

对比对象：同一标注集、同一 extractor_version，两次运行的逐文档 `matched / missing / spurious` 集合。

```
diff 文档数 = matched 集合不同 ∪ spurious 不同 ∪ missing 不同 的文档数
一致性 = 1 - diff文档数 / 已标注文档数
```

- mock：确定性，diff 必须为 0——不为 0 就是 pages 输入或代码漂移，先修。
- model：**temperature=0 也可能漂移**（本项目实测 3/3 diff）。每次报告必须带：运行日期、模型版本（`model-<prompt_version>`）、prompt 版本号；跨 run 对比先对齐这三样再谈升降。

## 7. 其他口径（空报告率 / 任职区间匹配）

- 空报告率：`report.facts` 为空的文档占比。
- 任职区间匹配：年份级（start 年 + end 年，"至今"=None）逐段配对，匹配数 / GT 区间总数。

## 9. 哪些指标最影响作品集叙事

- **F1 双路对照（0.364 vs 0.727）**——核心叙事：用真实标注证明"模型增量价值真实存在"，且不是拍脑袋。
- **转人工率 71.4%**——诚实披露：模型不完美、系统设计上把不确定项路由给人（HITL），而不是硬编分数。
- **证据定位有效率 100% + 引文可回溯**——可信度叙事：每条结论都能指回原文切片，这是多数玩具项目没有的。
- **P95 66.7s + token 量级**——工程落地意识：报得出延迟与成本量级，价目未配置就明说。
- **任职区间 mock 30/31 > model 22/31**——反向诚实项：规则在确定性年份抽取上反而更稳，说明"规则兜底 + 模型增强"的混合架构是有依据的，不是盲目上模型。
